# API Automation Validation Samples

API 자동화에서 반복적으로 사용하는 검증 로직을 모듈화한 예제입니다.

## 포함 내용

- HTTP 200 / 빈 응답 체크
- SUCCESS code / message 검증
- 필수 필드 검증
- 배열 내 허용 가능한 인증수단 검증
- createdAt / DATE 등 시간값 허용범위 검증
- 재시도 가능한 네트워크성 실패(`status = 0`) 예시
- AES-128-CBC 암·복호화 샘플
- Postman 스타일 Assertion 예제

실제 API 주소나 암호화 KEY/IV는 포함하지 않습니다.
